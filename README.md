## ✨ Key Features

- 🖥️ **Cinematic Login Experience** – A dramatic letter-drop animation for every login.
- 🪟 **Draggable Glassmorphism Windows** – Resizable, movable, and fullscreen-capable.
- 🤖 **AI-Powered Assistant (ADX Vision AI)** – Write code, answer questions, and control the OS via voice or text.
- 📝 **Built-in Apps** – Text Editor, CodePad, Notes, Markdown Notes, VPN, App Store, and more.
- 🎨 **Theme Engine** – Switch between Dark, Light, and Cyberpunk modes with a custom accent color picker.
- 🖼️ **Custom Wallpapers** – Upload images to personalize your desktop.
- 🔐 **Persistent Sessions** – Stay logged in for up to 7 days.
- 🌐 **IP-Based Storage** – All user data is stored securely using browser `localStorage`.
- 🚀 **Native Desktop Launcher** – Run the OS as a real desktop application using Python + Flask + pywebview.

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| **Frontend** | HTML5, CSS3, Vanilla JavaScript |

| **Voice Recognition** | Web Speech API (`webkitSpeechRecognition`) |
| **Data Persistence** | `localStorage` (IP-based session handling) |
| **Desktop Launcher** | Python 3, Flask, pywebview |

## 🚀 How to Run (Desktop Edition)

### 1. Install Python dependencies

```bash
pip install flask pywebview

2. Launch the OS
Windows: Double-click launch_os.bat

Mac/Linux: Run python ADX_OS_Server_Native_Short.py

The OS will automatically open in a native window.

🌐 Live Web Version
You can also try the OS directly in your browser:

🔐 Security Note
All API keys and Webhook URLs are stored securely in the browser's localStorage.

No sensitive keys are hardcoded in the source code.

The .gitignore file prevents .env and other secret files from being uploaded to GitHub.
