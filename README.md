# 🚀 ADX x OS – Desktop Edition

**ADX x OS** is a futuristic, web-based operating system simulator built with HTML, CSS, and JS.  
This repository contains the **Python Desktop Launcher** that runs the OS inside a native window (no browser tabs, no extra setup).

---

## 🌟 Key Features (Desktop Edition)

- ✅ **Native Window** – OS runs inside a clean, resizable desktop window (Chrome not opened separately).  
- ✅ **Single Click Launch** – Just run `launch_os.bat` and the OS starts instantly.  
- ✅ **Flask + Webview** – Lightweight Python server with native GUI support.  
- ✅ **Offline Support** – Works with local `index.html` file (no internet required after initial setup).  
- ✅ **Cross-Platform** – Works on Windows, Mac, and Linux (with small script changes).
